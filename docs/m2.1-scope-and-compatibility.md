## Preflight result and future rollout

- [x] Run the preflight against the current local-development database before enabling format assertion. Policy: 1 document; capabilities: 7 documents; invalid fields: 0; remediation: none.

On 2026-09-30, the preflight ran against the only current environment, local-development Compose PostgreSQL, before strict format assertion was enabled. Before deploying this strict build to any future environment with existing data, set `DATABASE_URL` to each target deployment database and run `node scripts/audit-policy-datetimes.mjs`. The read-only audit covers both `site_environment_policies` (`document.updated_at` and each `document.ingest_keys[].created_at`) and `site_capability_configurations` (`document.updated_at`). It reports site/environment identity and JSON field paths without timestamp values. Repair invalid policy timestamps through the supported policy update path; for malformed key creation timestamps, review the key's rotation or revocation through the supported management path. Repair invalid capability timestamps through the supported capability configuration write path. Rerun the audit and record the deployment target, date, aggregate findings, and remediation status without recording credentials or timestamp values.

The script fails closed when `DATABASE_URL` is missing or lacks a database name, explicit hostname, or single-host target. It ignores inherited libpq routing variables and requires a writable primary. It resolves exactly one matching table for each required table name from PostgreSQL catalogs, verifies each table kind and required columns, and quotes each schema before reading. It clears inherited `PGOPTIONS` and rejects URL `options` and `target_session_attrs` to keep the target and SQL context fixed. The local-development database audit and disposable PostgreSQL exercise are recorded in the [M2.4 parity assessment](m2.4-configuration-parity.md); hosted deployments are not currently in scope. The offline checker command is `node scripts/audit-policy-datetimes.mjs --fixtures`.

Before M2.2/M2.4 enables format assertion in production, set `DATABASE_URL` to each target deployment database and run `node scripts/audit-policy-datetimes.mjs`; repair every finding by updating the policy timestamp or reviewing a key revocation/rotation for malformed key creation timestamps. The script fails closed when `DATABASE_URL` is missing or lacks a database name, explicit hostname, or single-host target. It ignores inherited libpq routing variables and requires a writable primary. The script resolves the visible policy table and its schema from PostgreSQL catalogs for the target connection role, verifies its table kind and required columns, and quotes the schema before reading. It clears inherited `PGOPTIONS` and rejects URL `options` and `target_session_attrs` to keep the target and SQL context fixed. Local fixture verification is not a deployment database audit. The offline checker command is `node scripts/audit-policy-datetimes.mjs --fixtures`.
